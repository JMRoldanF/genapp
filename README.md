Hand-written parser test cases for Nomain v1.9.22 QA: small COBOL, JCL, Control-M, DB2 DDL and control-member files that each exercise one parser change shipped between BYOC v1.9.13 and v1.9.22 (Control-M AutoEdit names and values, JCL IF NOT, DSN refer-backs, unnamed steps, DD direction from COBOL file verbs, DB2 aliases/grants/seed-row members, legacy COBOL syntax). This is not production code, and the names, datasets and tables in it are synthetic.

`genapp-subset/` holds five programs and two copybooks copied unchanged from IBM's public CICS GenApp sample (https://github.com/cicsdev/cics-genapp, `base/src`), licensed under the Eclipse Public License 2.0. They give the QA run enough code to cancel and resume an analysis mid-explain.
